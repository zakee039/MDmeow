# MDmeow 发布视频 · 录屏说明

打开 `index.html` 即可播放；渲染器、字体、截图和样式均已打包在 assets 中。文档里的远程图片需要网络。

如果浏览器限制本地文件，可在此目录运行 `node serve.mjs`，再打开 http://127.0.0.1:5178 。

## 录制

画布为 1920 × 1080，自适应窗口。建议录制 16:9、1080p、30 或 60 fps。

- F：全屏；H：隐藏/显示控制栏和鼠标。
- A：自动播放/暂停（共 9 幕，约 122 秒，无配音，最后一幕停留）。
- →、空格、鼠标右键：下一幕；←：上一幕；R：回到开头。
- 1 / 2 / 3 / 4：跳到开场 / 低占用 / 设置 / 渲染。
- 渲染页可手动滚动全文，左侧目录跳到指定章节。

录制前先浏览最后的图文分镜，让网络图片完成加载，再按 R 回到开场、H 隐藏操作栏、A 开始。

## 素材与构建

实际测试文件为 `Markdown_综合渲染测试文档.md`（使用目录中已有的文件名）。未修改测试文档。
设置素材来自 release/MDmeow-1.7.8.exe 的真实界面，保存在 assets/settings-*.jpg。
手绘 Miku 是 assets/miku.svg，可无损缩放。
网页复用 ../src/editor.ts 和 ../src/styles.css 的实际渲染器，未替换成通用 Markdown 预览。
如修改源文档或渲染代码，从项目根目录运行 `node 视频/build.mjs` 重新打包。
内存与 CPU 数字是原图中的进程瞬时读数，并非所有环境的固定占用。

轻量截图来自 ../docs/assets/screenshots/lightweight.png，复制到 assets/lightweight.png 供独立播放。
