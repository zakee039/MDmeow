# MDmeow 发布站点

本地预览：`node serve.mjs`，访问 http://127.0.0.1:5179 。站点尚未部署公网。

页面随浏览器尺寸自适应，手机可上下滚动。点击页面前往下一页，也支持左右方向键。滚动、拖动或选中文字不会触发翻页。最后一页停留，刷新总是从首页开始。

无页码、自动播放、全屏或录屏控制栏。每页右上角与最后一页的下载按钮在当前页面跳转到 GitHub Releases 最新发布页。

连续点击左上角 App 图标五次（相邻两次不超过 1.4 秒），弹出项目自带的 Miku 彩蛋图。点击关闭按钮、背景或按 Esc 关闭，不影响当前页。

原“视频”版本仅同步了真实 App 图标，保留录屏功能。
