# MDmeow

**یک ویرایشگر Markdown مینیمال، قابل‌حمل و WYSIWYG.**

Markdown را تایپ کنید و همان لحظه قالب‌بندی‌شده ببینید — به سبک Typora. آن‌قدر
توانمند که برای نوشتنِ واقعی کافی است (جدول‌ها، فرمول‌ها، کد، پانویس‌ها،
راست‌به‌چپ)، و در عین حال یک فایل اجراییِ حدوداً ۷ مگابایتی که فوری باز می‌شود و
سر راه شما نیست.

***

## چرا MDmeow

- **به‌طرز فریبنده‌ای توانمند.** ویرایش درجا (WYSIWYG)، سندها به‌صورت زبانه،
  منوی بلوک، جدول‌های GFM با کشیدن برای مرتب‌سازی، فرمول‌های KaTeX، کدِ رنگ‌آمیزی‌شده،
  جست‌وجو و جایگزینی، پشتیبانی از راست‌به‌چپ، و خروجی HTML/PDF مستقل.
- **بسیار سبک.** بدون Electron. MDmeow روی [Tauri](https://tauri.app) و WebView خودِ
  سیستم‌عامل ساخته شده است، بنابراین کل برنامه **یک فایل اجراییِ قابل‌حمل در حدود
  ۷ مگابایت** است — بدون نیاز به نصب، بدون چیزی برای استخراج، بدون سرویس پس‌زمینه.
- **واقعاً سریع.** هستهٔ آن Rust است، پنجره بومی است و راه‌اندازی سرد عملاً آنی
  است. مثل یک ویرایشگر متن حس می‌شود، نه یک برنامهٔ وب.
- **قابل‌حمل از پایه.** یک `settings.toml` قابل‌ویرایش با دست کنار فایل اجرایی قرار
  دارد. `mdmeow.exe` را روی یک حافظهٔ USB بگذارید و تنظیمات‌تان همراه‌تان می‌آیند.

## ویژگی‌ها

### ✍️ ویرایش درجای WYSIWYG

با نیروی [Milkdown Crepe](https://milkdown.dev) (ProseMirror). عنوان‌ها، ضخیم،
فهرست‌ها، نقل‌قول‌ها و بقیه هنگام تایپ قالب‌بندی می‌شوند — اما سندِ روی دیسک همیشه
Markdownِ ساده و قابل‌حمل است.

### 🔗 پیوند بدون درگیری با نحو

مقداری متن را انتخاب کنید، سپس **یک نشانی را با `Ctrl/Cmd+V` بچسبانید** — متنِ
انتخاب‌شده به متنِ پیوند و نشانیِ چسبانده‌شده به مقصدِ آن تبدیل می‌شود. نه تایپِ
`[]()`، نه پنجرهٔ گفت‌وگو. صفحه‌کلید را ترجیح می‌دهید؟ متن را انتخاب کنید و
**`Ctrl/Cmd+K`** را بزنید تا با نشانیِ داخل کلیپ‌بورد به پیوند تبدیل شود (یا یک
پیوندِ خالی برای پر کردن).

### 🖼️ تصویرهایی که خودشان نمایش داده می‌شوند

`![alt](picture.png)` در ویرایشگر به‌صورت درجا نمایش داده می‌شود، از جمله
**مسیرهای نسبی** که نسبت به پوشهٔ خودِ سند حل می‌شوند
(`./assets/diagram.png`، `../shared/logo.svg`) و مسیرهای محلیِ مطلق — نه فقط
نشانی‌های `http(s)`. از منوی بلوکِ `⠿` یکی اضافه کنید («Image»)، سپس یک پیوند
بچسبانید یا یک فایل انتخاب کنید.

### 🧱 منوی بلوک

روی هر بلوک بروید و روی دکمهٔ `⠿` کلیک کنید تا منویی سریع باز شود که روی همان
بلوک عمل می‌کند:

- **تبدیل به** — متن، عنوان ۱ تا ۳، فهرست نقطه‌ای، فهرست شماره‌دار، نقل‌قول، بلوک کد
  یا **جدول**
- **درج** یک جدول، یک تصویر، یک خط جداکننده یا یک خط خالی در بالا/پایین
- **تکثیر** یا **حذف** بلوک

نوعِ بلوکِ فعلی برجسته می‌شود تا همیشه بدانید چه چیزی را ویرایش می‌کنید. نوع‌هایِ
«تبدیل به» میان‌بُرِ صفحه‌کلید هم دارند — `Ctrl/Cmd+0`–`7` (متن، عنوان ۱ تا ۳،
فهرست نقطه‌ای، فهرست شماره‌دار، نقل‌قول، بلوک کد) — که مثل منو روی گزینش اعمال
می‌شود.

### 😀 ایموجی

`Ctrl/Cmd+.` را بزنید تا یک انتخابگرِ ایموجیِ قابل‌جست‌وجو باز شود، یا کافی است
یک `:shortcode:` بنویسید (مثلِ `:tada:` ← 🎉 و `:+1:` ← 👍) که هنگامِ بستنِ
دونقطه به ایموجی تبدیل می‌شود. یونیکدِ بومی — بدون تصویر و بدون دانلود.

### 📑 زبانه‌ها با بازیابی نشست

چند سند را به‌صورت زبانه باز کنید. MDmeow را ببندید، دوباره باز کنید، و زبانه‌های
شما — حتی موقعیتِ اسکرول‌شان — برمی‌گردند. (در پیکربندی قابل خاموش کردن است.)

### 👁️ نمای منبع

با `Ctrl/Cmd+/` بین ویرایشگرِ غنی و **Markdownِ خام** در یک ناحیهٔ متنیِ ساده
جابه‌جا شوید. `Tab` / `Shift+Tab` خطوط انتخاب‌شده را تورفتگی می‌دهند و برمی‌گردانند،
و واگردِ بومی همچنان کار می‌کند. موقعیتِ خواندن هنگام جابه‌جایی حفظ می‌شود.

### 🔍 جست‌وجو و جایگزینی

`Ctrl/Cmd+F` برای جست‌وجو، `Ctrl/Cmd+H` برای جایگزینی — هم در ویرایشگر WYSIWYG و هم
در نمای منبع کار می‌کند.

### 📊 جدول‌هایی که سربه‌راه‌اند

جدول‌های کاملِ GitHub‑Flavored Markdown. **ردیف‌ها و ستون‌ها را بکشید** تا مرتب
شوند، یک جدول را مستقیم از منوی بلوک درج کنید، و جدول‌هایی که با دست تایپ شده‌اند
هنگام ذخیره در فایلِ `.md` به‌طور خودکار **هم‌تراز و پُر** می‌شوند تا Markdownِ خام
خوانا بماند.

### 🧮 فرمول و 💻 کد

- فرمول‌های **KaTeX**، درون‌خطی (`$…$`) و نمایشی (`$$…$$`)
- **بلوک‌های کد** با رنگ‌آمیزیِ نحوی و تشخیص زبان

به‌علاوهٔ بقیهٔ GFM: فهرست‌های کار، پانویس‌ها، خط‌خورده، پیوندهای خودکار.

### 📤 خروجی

- **HTMLِ مستقل** — یک فایلِ واحد با سبک‌های KaTeX و رنگ‌آمیزیِ درون‌گنجانده، بدون
  نیاز به میزبانی. تصویرهای محلی به‌صورت data‑URL درون‌گنجانده می‌شوند.
- **PDF** از طریق پنجرهٔ چاپِ سیستم

### 🎨 پوسته‌ها و ظاهر

پوستهٔ روشن و تیره که به‌طور پیش‌فرض از سیستم‌عامل پیروی می‌کند، با کلیدِ تعویضِ
دستی. قلمِ ویرایشگر، اندازهٔ قلم، قلمِ نمای منبع و رنگِ تأکید همگی قابل‌پیکربندی‌اند.

### 🗂️ پیوند فایل‌ها

MDmeow را برنامهٔ پیش‌فرضِ فایل‌های `.md` / `.markdown` قرار دهید (از طریق نصب‌کننده).
با دوبار کلیک روی یک فایلِ Markdown، آن فایل در زبانه‌ای تازه از پنجرهٔ در حالِ
اجرا باز می‌شود.

### ⚙️ تنظیمات: رابط گرافیکی یا فایل

هر تنظیمی را می‌توان از داخل برنامه تغییر داد — دکمهٔ تنظیمات در نوار ابزار (یا
`Ctrl/Cmd+,`) صفحهٔ تنظیمات را با یک چرخش روی ویرایشگر باز می‌کند، با یک کنترل
برای هر گزینه؛ تغییرها بی‌درنگ اعمال و ذخیره می‌شوند. یا همان `settings.toml`ِ
واحد و دارای توضیح کنار فایل اجرایی را در هر ویرایشگرِ متنی ویرایش کنید — MDmeow
**تغییر را ظرف یک ثانیه می‌گیرد، بدون راه‌اندازیِ دوباره**. اگر پوشهٔ برنامه
فقط‌خواندنی باشد، MDmeow به پوشهٔ پیکربندیِ سیستم‌عامل برمی‌گردد و در پنجره به شما
اطلاع می‌دهد. هر انتشار یک `settings.example.toml`ِ کاملاً توضیح‌دار هم همراه دارد.

### 🌍 انگلیسی و آلمانی

رابط برنامه به **انگلیسی و آلمانی** در دسترس است و به‌طور پیش‌فرض از زبان
سیستم پیروی می‌کند (`language = "system" | "en" | "de"`، قابل‌تغییر در تنظیمات).

## Download

آخرین ساخت را از صفحهٔ [Releases](../../releases) بگیرید.

- **ویندوز (x64)** — هم‌اکنون در دسترس: `mdmeow.exe`ِ قابل‌حمل (\~۷ مگابایت، بدون
  نصب) یا نصب‌کنندهٔ NSIS
- **macOS** (x64 + arm64) و **لینوکس** (x64 + arm64 با AppImage) — *به‌زودی.*
  خط لولهٔ انتشارِ چندسکویی آماده است
  ([`.github/workflows/release.yml`](.github/workflows/release.yml))؛ این ساخت‌ها
  با یک انتشارِ برچسب‌دارِ آینده می‌آیند. تا آن زمان روی سیستمِ مقصد از روی منبع
  بسازید (بخش [Building](README.md#building)) — MDmeow یک برنامهٔ Tauri است و روی هر
  سه اجرا می‌شود.

ساخت‌ها **امضا یا notarize نشده‌اند**، پس ممکن است سیستم‌عامل هنگام نخستین اجرا
هشدار دهد:

- **ویندوز** — SmartScreen: *More info → Run anyway*
- **macOS** — کلیک راست روی برنامه → *Open*، یا
  `xattr -dr com.apple.quarantine /path/to/MDmeow.app`
- **لینوکس** — `chmod +x MDmeow*.AppImage` و اجرا

با هر انتشار، جمع‌های کنترلیِ SHA‑256 منتشر می‌شوند.

## پیکربندی

`settings.toml` کنار فایل اجرایی قرار دارد (در macOS: کنار بستهٔ `.app`)، یا در
غیر این صورت در پوشهٔ پیکربندیِ سیستم‌عامل. بخشِ بالایی برای ویرایش با دست در نظر
گرفته شده و به‌صورت زنده بارگذاری می‌شود (توضیح‌های `#` مانند خودِ فایل انگلیسی
می‌مانند):

```toml
language = "system"         # system (follow the OS) | en | de
spellcheck = true
quit_on_escape = false      # press Esc to quit
list_marker = "*"           # bullet-list marker on save: * | - | +
show_path = false           # show the full file path in the header, not just the name
open_last_session = true    # reopen the previous session's tabs on startup
always_show_tabbar = false  # keep the tab bar visible even with only one file open
editor_font = ""            # WYSIWYG font family (blank = default)
editor_font_size = 16       # headings scale from this
source_font = ""            # Markdown source font (monospace)
source_font_size = 15
accent = "#39C5BB"         # accent colour; reset/default is Miku teal

# below this line: managed by the app — window geometry, open tabs
```

## ساخت از منبع

پیش‌نیازها:

- Rust (نسخهٔ stable؛ زنجیرهٔ ابزارِ MSVC در ویندوز) — <https://rustup.rs>
- Node 20+ و `pnpm`
- وابستگی‌های WebViewِ سکو — <https://tauri.app/start/prerequisites/>

```bash
pnpm install
pnpm tauri dev                       # run with hot reload
pnpm tauri build                     # release bundles for the host OS
pnpm tauri build --bundles nsis      # Windows: installer + portable exe
pnpm exec tsc --noEmit               # frontend typecheck
cargo test --manifest-path src-tauri/Cargo.toml   # Rust unit tests
```

**بریدنِ یک انتشار:** `version` را در **هر دو** فایلِ `package.json` و
`src-tauri/tauri.conf.json` بالا ببرید، سپس یک برچسبِ `v*` را push کنید —
`.github/workflows/release.yml` نسخه‌های ویندوز / macOS / لینوکس (x64 + arm64) را
می‌سازد و یک پیش‌نویسِ انتشارِ GitHub با جمع‌های کنترلی باز می‌کند.

MDmeow را گسترش می‌دهید؟ **[ARCHITECTURE.md](ARCHITECTURE.md)** را بخوانید — همهٔ
فایل‌ها را نقشه‌برداری می‌کند و نشان می‌دهد چگونه دکمه‌های نوار ابزار، مواردِ منوی
بلوک، تنظیمات و فرمان‌ها را اضافه کنید.
